# Preço do Café — Holt-Winters (arquivo histórico)

Repositório histórico do trabalho de modelagem de preços do café brasileiro realizado em colaboração com o Prof. Dr. Carlos Tadeu S. Dias (USP). Contém o código originalmente executado no Google Colab, a planilha histórica e materiais associados ao resumo publicado em 2024.

## Evolução do projeto

As análises foram posteriormente revisadas, ampliadas e reorganizadas no projeto **Coffee Quant**, que reúne modelagem de séries temporais, validação temporal, indicadores quantitativos de risco e dashboard interativo.

- **Projeto atualizado:** https://github.com/iamdatagabs/coffee_quant
- **Dashboard:** https://iamdatagabs.github.io/coffee_quant/

## Nota metodológica

O código deste repositório pode divergir dos resultados e procedimentos descritos no resumo de 2024, devido a refatorações e atualizações analíticas posteriores. Para reproduzir a versão mais recente, consulte o Coffee Quant e sua documentação.

Este repositório é mantido como registro histórico e não deve ser interpretado como a versão mais atual do pipeline.
